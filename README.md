## Greenhouse:

Greenhouse is a board for community beautification.

### How it works:

- Log onto the website, create or suggest a community project.
- Each project board is either hosted by a government official or an individual
- A project board lets users host events around their community, for beautification or even just for fun!

## Backend development

The backend uses Java, storing objects that contain information on each event. 
Spring boot is the framework used to develop the backend. This functions
by combining multiple libraries together, so we do not have to worry
about beams or dependencies.

The backend allows api requests to the front end and vice-versa. This is done through
sprint-boot accessing local port 8080, and Vite using 5737. 

This functions as a prototype using ram as storage, resulting in all data being lost in API closure.

## AI Usage
